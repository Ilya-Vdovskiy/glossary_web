# Глоссарий по зарубежной литературе XIX века

Чистый MVP на Next.js для ДО-курса НовГУ. Данные хранятся локально: исходный `.docx` разбирается отдельным Node.js-скриптом, а сайт читает готовый JSON.

## Команды

```bash
npm install
npm run parse:glossary
npm run dev
```

Откройте `http://localhost:3000`.

## Данные

- исходный документ: `термины_все_исправленные_с_оглавлением.docx`
- результат парсинга: `src/data/glossary.json`
- типы данных: `src/types/glossary.ts`
- доступ к данным и маршрутам: `src/lib/glossary.ts`

## Как обновить глоссарий

1. Замените `.docx` в корне проекта новым файлом с той же структурой.
2. Запустите `npm run parse:glossary`.
3. Проверьте сайт через `npm run dev`.

Парсер можно запускать повторно: он перезаписывает `src/data/glossary.json`.
